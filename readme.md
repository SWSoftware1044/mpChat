# mpChat
Model-Protocol (or mp) Chat is a Python application I developed to talk to AI models from the desktop rather than a web browser. It is intended for use specifically with OpenRouter, and some optional functionality supports that, but can be used with other APIs as well.

# Quickstart
- Install dependencies from requirements.txt
- Create an .env file with at least `API_KEY` refering to your (OpenRouter) API key. If a different API is required, point `API_BASE` to it.
- Click on `chat.py` to open the interface.
